# 🎮 PokeAuc

PokeAuc is a Pokémon auction web application where players can participate in auctions to collect Pokémon using virtual credits.

## 🌐 Live Website

**Play here:** https://pokeauc.web.app

## ✨ Features

* Pokémon auction system.
* Player rooms for multiplayer auctions.
* Virtual credits for bidding.
* Live bidding and auction updates.
* Pokémon inventory and purchase tracking.
* User authentication.
* Bidding history and player management.

## 🔐 Admin Access

* Only the admin can start an auction.
* Auctions are started manually by the admin.
* Admin access is granted only after manual approval.
* Regular players cannot start auctions.

## 🚧 Project Status

PokeAuc is live and under development. Some features and workflows may still be evolving.

## 🛠️ Tech Stack

* React
* Vite
* JavaScript
* Firebase Authentication
* Cloud Firestore
* Firebase Hosting

## 🎯 Purpose

PokeAuc provides a platform for Pokémon fans to organize and participate in competitive Pokémon auctions with friends.
